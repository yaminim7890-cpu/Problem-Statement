# 1. Banking Loan Eligibility Pre-Screening System
• Developed a JavaScript-based application to check customers' preliminary loan eligibility.  
• Collects customer details such as income, employment type, requested loan amount, credit score, and existing EMI.  
• Uses conditional statements (if, else if, and else) to evaluate eligibility.  
• Classifies customers into Standard, Restricted, or Not Eligible categories based on predefined business rules.  
• Checks the existing EMI against the assumed income-based limit.  
• Displays the customer's eligibility status and remarks.  
• Helps simplify the initial loan screening process without providing actual loan approval.

**Technologies Used**: JavaScript, Node.js

# 2. E-Commerce Order Discount & Delivery System
• Developed a JavaScript-based application to calculate discounts and delivery charges for online orders.  
• Uses customer category, order amount, and delivery location to determine pricing.  
• Applies different discount percentages for Premium and Regular customers.  
• Provides an additional discount for orders above ₹5,000, subject to the maximum discount limit.  
• Calculates delivery charges based on order value and delivery location.  
• Offers free delivery for orders of ₹3,000 or more.  
• Displays the original order amount, discount, delivery charge, and final payable amount.  
• Generates a clear order summary to simplify the checkout calculation process.

**Technologies Used**: JavaScript, Node.js
